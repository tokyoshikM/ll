# АвторLab — ML Demo, GitHub Pages

Полностью статический сайт на HTML/CSS/JS. ML-модель исполняется в браузере; API-ключ, backend, Python на хостинге не нужны.

## Публикация на GitHub Pages

1. Создайте репозиторий (например, `authorlab`).
2. Загрузите **содержимое** этого архива в корень ветки `main` (index.html должен быть в корне).
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
4. Откройте `https://ВАШ-ЛОГИН.github.io/authorlab/` после появления ссылки в Pages. Для другого имени репозитория изменится последний сегмент ссылки.

Для локального запуска (не через file://): `python -m http.server 8000` и `http://localhost:8000`.

## Реальное машинное обучение

`training/train.py` читает CSV с метками `human` и `synthetic`, обучает **TfidfVectorizer(char ngrams 3..5) + LogisticRegression** и экспортирует `model/model.json`. `model/predict.js` реализует совместимый алгоритм подсчета TF-IDF и логистической регрессии без Python в браузере.

Переобучение: `pip install -r training/requirements.txt`, `python training/train.py`, закоммитьте обновлённый `model/model.json`.

## ⚠️ Научная добросовестность

Текущий датасет **демонстрационный**: 24 фрагмента классической поэзии и 48 **процедурно составленных шаблонных строк**. Это **не** настоящие ответы ChatGPT или другой LLM. Модель различает классы в указанном наборе, но **не валидирована** для выявления ИИ-авторства. Её числовой score нельзя трактовать как вероятность того, что текст написал ИИ. Не используйте в оценивании учащихся или обвинениях в плагиате.

Для реального исследования соберите размеченный корпус подтверждённых русских человеческих стихотворений и реальных генераций нескольких LLM, исключите утечки между обучением и тестом (группируйте по авторам, источникам и prompt), проведите независимое тестирование и калибровку. Укажите precision/recall/FPR отдельно по длинам и типам текстов. Сравните с наивным baseline. До валидации формулируйте вывод только как экспериментальную гипотезу.

## Разделы

- Эксперимент на 8 фрагментах с раскрытием ответов
- ML-детектор, работающий локально
- Результаты в localStorage, экспорт JSON

Результаты участников не объединяются между устройствами: GitHub Pages не предоставляет серверную базу данных.
